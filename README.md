# Agent education — worked examples

Companion files for the talk *Beyond Jet Ski*. Each file is a small, complete example of one idea from the slides.

## Prompts, loops, graphs
| File | What it shows |
|---|---|
| [01-prompt-task-contract.txt](01-prompt-task-contract.txt) | A weak prompt next to a full task contract: outcome, context, constraints, authority, acceptance tests, stopping conditions, reporting |
| [02-loop-trace.txt](02-loop-trace.txt) | Five turns of one agent's loop on the GPU queue case: think, act, observe, decide |
| [03-graph-three-prompts.txt](03-graph-three-prompts.txt) | One audit split across a lead, ten workers, verifiers and a sequencer, and how each role's prompt differs |
